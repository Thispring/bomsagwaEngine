# VS Code macOS C++ 개발 단축키

macOS에서 **VS Code + C++**로 개발할 때 자주 사용하는 단축키를 정리한 문서입니다.

C++ 개발에서 자주 발생하는 **파일 탐색, 헤더/소스 전환, 코드 탐색, 검색, 편집, 리팩토링, 터미널, 디버깅** 작업을 중심으로 구성했습니다.

> 참고: 일부 C++ 관련 기능은 VS Code 기본 기능이 아니라 C/C++ 확장 등의 확장 프로그램에서 제공됩니다.  
> 단축키가 동작하지 않는 경우 `⌘K ⌘S`에서 현재 Keybinding을 확인하세요.

---

# 8. C++ 헤더 ↔ 소스 전환

C++ 개발에서 매우 자주 사용하는 기능입니다.

예:

```text
Player.h
   ↕
Player.cpp
```

### 기본적인 방법

C/C++ 확장이 제공하는 `Switch Header/Source` 기능을 사용할 수 있습니다.

Command Palette:

```text
⇧⌘P
```

→

```text
C/C++: Switch Header/Source
```

를 검색합니다.

### 단축키

환경에 따라 다음과 같이 `⌥O`가 해당 명령에 등록되어 있을 수 있습니다.

```text
⌥O
```

단축키가 동작하지 않는다면:

```text
⌘K ⌘S
```

→ `Switch Header/Source`

를 검색하여 현재 Keybinding을 확인합니다.

> C/C++ 확장의 버전 및 설치된 다른 확장에 따라 기본 단축키가 다를 수 있습니다.

---

# 9. 정의로 이동

## `F12`

현재 선택한 함수, 클래스, 변수 등의 정의로 이동합니다.

예:

```cpp
player.Move();
```

에서 `Move()`에 커서를 놓고:

```text
F12
```

를 누르면 `Move()`의 정의 위치로 이동할 수 있습니다.

---

# 10. 정의 미리보기

## `⌥F12`

정의가 있는 파일로 완전히 이동하지 않고 현재 코드 위치에서 정의 내용을 미리 볼 수 있습니다.

코드 흐름을 유지하면서 특정 함수의 구현을 확인할 때 유용합니다.

---

# 11. 모든 참조 찾기

## `⇧F12`

현재 심볼이 프로젝트에서 어디에서 사용되는지 확인합니다.

예:

```cpp
GameManager
```

를 선택하고:

```text
⇧F12
```

를 누르면 해당 클래스나 심볼의 사용 위치를 확인할 수 있습니다.

C++ 프로젝트에서 클래스 간 의존성을 파악할 때 매우 유용합니다.

---

# 12. 심볼 검색

## 현재 파일

### `⇧⌘O`

현재 파일에 존재하는 클래스, 함수, 변수 등의 심볼을 검색합니다.

예:

```text
Player.cpp

├── Player
├── Initialize
├── Update
├── Move
├── Attack
└── Reset
```

처럼 함수가 많은 파일에서 원하는 함수를 빠르게 찾을 수 있습니다.

## 전체 프로젝트

### `⌘T`

워크스페이스 전체의 심볼을 검색합니다.

클래스나 함수 이름을 알고 있지만 어느 파일에 있는지 모를 때 유용합니다.

---

# 13. Quick Fix / Code Action

## `⌘.`

현재 코드에서 사용할 수 있는 수정 및 코드 작업을 표시합니다.

C++ 확장에서는 상황에 따라 다음과 같은 작업이 제공될 수 있습니다.

```text
Include 추가
이름 변경
코드 수정
Quick Fix
```

---

# 14. 이름 변경

## `F2`

현재 심볼의 이름을 변경합니다.

예:

```cpp
int PlayerCount;
```

를

```cpp
int ActivePlayerCount;
```

로 변경하고 싶을 때:

```text
F2
```

를 사용합니다.

일반적인 텍스트 검색/치환과 달리 **코드의 심볼을 기준으로 변경**할 수 있어 C++에서 특히 유용합니다.

# 21. 디버깅

### 자주 사용하는 조합

```text

```

```text

```

```text

```

```text

```

```text
⇧F11
```

# 25. 단축키가 동작하지 않을 때

VS Code의 키보드 단축키 설정은 다음 단축키로 열 수 있습니다.

```text
⌘K ⌘S
```

검색창에서 원하는 명령을 검색합니다.

예:

```text
Switch Header/Source
Go to Definition
Find All References
Rename Symbol
Format Document
Move Line Down
Duplicate Selection
```

특히 C++ 확장 프로그램을 여러 개 설치한 경우 같은 기능에 여러 단축키가 등록되어 충돌할 수 있으므로 이 메뉴에서 실제 Keybinding을 확인하는 것이 좋습니다.

# 26. 개인 추천 단축키 세트

macOS에서 C++ 개발을 한다면 다음 정도를 손에 익혀두는 것을 추천합니다.

```text
파일 열기             ⌘P
Command Palette       ⇧⌘P

헤더 ↔ 소스           ⌥O
정의로 이동            F12
정의 미리보기          ⌥F12
참조 찾기              ⇧F12
이름 변경              F2
Quick Fix             ⌘.

현재 파일 심볼        ⇧⌘O
전체 심볼              ⌘T
전체 검색              ⇧⌘F

줄 위/아래 이동        ⌥↑ / ⌥↓
줄 복제                ⇧⌥↑ / ⇧⌥↓
줄 삭제                ⇧⌘K
주석                   ⌘/
포맷팅                 ⇧⌥F

터미널                 ⌃`
디버깅 시작             F5
Breakpoint             F9
Step Over              F10
Step Into              F11
```

이 정도의 단축키만 익혀도 파일 탐색과 코드 이동, C++ 코드 분석 및 수정 작업의 상당 부분을 키보드만으로 처리할 수 있습니다.
